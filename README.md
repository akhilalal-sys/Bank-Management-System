\# Bank Management System



\## Overview



The Bank Management System is a desktop application developed using C# Windows Forms and SQL Server. It helps manage banking operations such as customer management, account handling, transactions, employee records, and loan management.



\---



\## Features



\* User Login Authentication

\* Customer Management

\* Employee Management

\* Account Creation

\* Deposit and Withdrawal

\* Transaction Management

\* Loan Management

\* Dashboard Interface

\* SQL Server Database Connectivity



\---



\## Technologies Used



\* C#

\* Windows Forms

\* .NET Framework

\* SQL Server

\* ADO.NET

\* Visual Studio

\## Project Modules



1\. Login Module

\## Database



The project uses SQL Server database for storing:



\* Customer Details

\* Employee Details

\* Account Information

\* Transaction Records

\* Loan Information



\---



\## How to Run



1\. Clone the repository

2\. Open the solution in Visual Studio

3\. Configure SQL Server connection string

4\. Run the SQL script to create database tables

5\. Build and run the project
